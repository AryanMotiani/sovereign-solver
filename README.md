# Sovereign Optimization Solver Core (SIH)

An industrial-grade, sovereign mathematical optimization engine built **from scratch from first principles**, supporting Linear Programming (LP), Mixed-Integer Linear Programming (MILP), and Quadratic Programming (QP).

## Project Mission
To break dependence on proprietary foreign mathematical solvers (e.g., Gurobi, CPLEX, FICO Xpress) in critical Indian industrial sectors (refineries, power grids, logistics, manufacturing) by providing a transparent, numerically resilient, and sovereign solver core.
